주요일정 캘린더 동기화

한글(.hwpx) 주요일정 문서를 읽어 Google 캘린더에 반영하는 개인용 Windows 도구입니다.

무엇을 하는 프로그램인가

사무실에서는 매일 한 장짜리 주요일정 문서가 새로 만들어집니다. 날짜, 시간, 행사명, 장소, 참석자, 주관부서가 표로 정리된 문서입니다. 이 프로그램은 지정한 폴더에 그 문서가 저장되면 자동으로 내용을 읽어, 사용자의 Google 캘린더에 일정으로 옮깁니다.

어제 문서에 이미 들어 있던 일정은 다시 만들지 않고, 시간이나 이름이 바뀐 일정은 최신 문서 내용으로 덮어씁니다. 문서에서 사라진 일정은 지우지 않고 제목 앞에 표시만 남깁니다.

Google 계정 권한을 왜 요청하나

일정을 캘린더에 쓰려면 Google 계정의 캘린더 접근 권한이 필요합니다. 요청하는 권한은 아래 두 가지뿐입니다.

앱이 만든 보조 캘린더 관리
calendar.app.created — 이 프로그램이 직접 만든 전용 캘린더 하나에만 일정을 쓰고 읽습니다. 사용자의 기본 캘린더나 다른 캘린더에는 접근할 수 없습니다.
계정 이메일 확인
userinfo.email, openid — 여러 계정을 등록했을 때 어느 계정인지 화면에 구분해 표시하기 위해 이메일 주소만 읽습니다.

어디서 실행되나

사용자의 Windows PC에서만 실행됩니다. 서버가 없고, 문서 내용이나 캘린더 일정이 제작자에게 전송되지 않습니다. 데이터 처리 방식은 개인정보처리방침에 자세히 적어 두었습니다.

이용 범위

공개 배포를 목적으로 하지 않는 개인 업무용 도구이며, 제작자가 직접 아는 소수만 사용합니다. Google 검증을 받지 않았으므로 로그인할 때 확인되지 않은 앱이라는 안내 화면이 한 번 표시됩니다.
