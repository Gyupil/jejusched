개인정보처리방침

주요일정 캘린더 동기화 · 시행일 2026년 9월 16일

이 문서는 주요일정 캘린더 동기화(이하 "프로그램")가 Google 사용자 데이터를 포함한 정보를 어떻게 접근, 이용, 저장, 공유하는지 설명합니다. 프로그램은 사용자의 Windows PC에서만 동작하며 제작자가 운영하는 서버가 없습니다.

접근하는 정보

  • Google 계정 이메일 주소 — 등록된 계정을 화면에 구분해 표시하는 용도로만 읽습니다.
  • 프로그램이 만든 보조 캘린더의 일정 — 프로그램이 직접 생성한 전용 캘린더 하나의 일정만 읽고 씁니다. 사용자의 기본 캘린더를 비롯한 다른 캘린더에는 접근 권한이 없습니다.
  • 지정 폴더의 주요일정 문서 — 사용자가 지정한 로컬 폴더의 .hwpx 파일을 읽습니다.

이용 목적

읽어 들인 정보는 문서의 일정을 캘린더에 반영하는 목적으로만 사용합니다. 구체적으로는 새 일정 추가, 변경된 일정 갱신, 문서에서 빠진 일정 표시, 그리고 이미 등록된 일정과의 중복 판단에 쓰입니다. 광고, 프로파일링, 통계 수집, 모델 학습 등 다른 목적으로는 사용하지 않습니다.

저장 위치와 기간

  • Google 인증 토큰은 사용자 PC의 사용자 계정 폴더에 운영체제 암호화 기능으로 보호해 저장합니다. 외부로 전송되지 않습니다.
  • 동기화 상태(어떤 일정을 언제 등록했는지)는 같은 위치의 로컬 데이터베이스 파일에 저장합니다.
  • 프로그램에서 계정을 삭제하면 해당 토큰을 폐기하고 저장된 기록을 지웁니다. 프로그램을 삭제하면 모든 로컬 데이터가 함께 사라집니다.

제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 다만 아래 한 가지 예외가 있습니다.

중복 일정 판단을 위한 Google Gemini API 이용. 같은 일정이 표기만 달리 적힌 경우를 가려내기 위해, 판단이 필요한 일정에 한해 행사명, 시간, 장소, 참석자, 주관부서를 Google Gemini API로 전송해 동일 여부를 묻습니다. 전송은 문서 한 건당 최대 1회이며, 이름이나 시간이 정확히 일치해 기계적으로 판단할 수 있는 일정은 전송하지 않습니다. 캘린더 전체 내용이나 계정 정보는 전송하지 않습니다. 이 기능은 프로그램 설정에서 끌 수 있고, 참석자와 장소를 전송 대상에서 제외하는 설정도 따로 제공합니다. 무료 등급 API 이용 시 전송 내용이 Google의 서비스 개선에 활용될 수 있으므로, 민감한 내용을 다루는 경우 이 기능을 끄고 사용하시기 바랍니다.

Google API 서비스 사용자 데이터 정책

프로그램이 Google API로부터 받은 정보의 이용 및 다른 앱으로의 이전은 제한적 사용 요건(Limited Use)을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

권한 철회

프로그램의 설정 화면에서 계정을 삭제하거나, Google 계정 권한 관리 페이지에서 직접 접근을 해제할 수 있습니다. 권한을 해제해도 이미 캘린더에 기록된 일정은 남으며, 필요하면 캘린더에서 직접 지우면 됩니다.

아동 관련

업무용 도구이며 아동을 대상으로 하지 않습니다. 아동의 정보를 의도적으로 수집하지 않습니다.
